# E-Commerce Sales SQL Database

## 📌 Project Overview

A small e-commerce sales database built using MySQL to manage customers, products, orders, and order items.

## 🛠️ Technologies Used

- MySQL
- SQL

## 🗄️ Database Tables

### Customers
Stores customer information such as name, email, city, and registration date.

### Products
Stores product name, category, price, and stock information.

### Orders
Stores customer orders, order dates, and order status.

### Order Items
Stores products and quantities associated with each order.

## 📊 Analysis Performed

- Total revenue calculation
- Revenue by product
- Highest revenue product
- Customer spending analysis
- Highest spending customer
- Sales by category
- Monthly sales
- Low-stock products
- Order analysis

## 🎯 Project Purpose

This project was created to practice SQL database design, relationships, joins, aggregation, filtering, and basic e-commerce sales analysis using MySQL.
